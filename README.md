# Again

Веб-приложение для запоминания слов и фраз: интервальные повторения, ввод с клавиатуры, проверка ИИ, пополнение карточек через MCP.

## Цель

За 5 дней до поездки закрыть базовые сценарии на английском: отель, парковка, магазин, цифры на слух. Дальше — универсальный тренажёр для любых колод.

## Пользователь умеет

- Регистрироваться и входить.
- Создавать личные колоды, подписываться на готовые.
- Задавать колоде дедлайн: до даты все карточки показываются ежедневно.
- Учить новые слова, повторять, идти смешанным режимом.
- Выдавать токен, по которому Claude через MCP добавляет карточки.

## Запись

Три вида: слово, фраза, предложение. Поля: текст, перевод, транскрипция, аудио, картинка, пример с переводом.

## Навыки и упражнения

Прогресс считается отдельно по каждому навыку записи.

| Навык | Упражнение |
| --- | --- |
| Узнать | Выбор перевода из вариантов |
| Вспомнить | Ввод с клавиатуры (основное), фраза с пропуском |
| Понять на слух | Диктант, в том числе цифр и цен |
| Употребить | Составить предложение, проверяет ИИ |

## Оценка

Пользователь оценку не выбирает, она выводится из ответа.

| Ответ | Оценка |
| --- | --- |
| Верно без подсказок | Good |
| Верно с подсказкой или опечаткой | Hard |
| Неверно, «Не помню» | Again |
| Проверка ИИ | Модель возвращает оценку 1–4 и разбор ошибок |

Слова сверяются побуквенно, ИИ вызывается только для предложений.

## Расписание

- Алгоритм FSRS, готовая библиотека, целевое запоминание 90%.
- Again возвращает карточку в текущую тренировку.
- При завале — дневной лимит, первыми идут карточки, ближайшие к забыванию.
- История ответов не удаляется: по ней пересчитывается прогресс.

## Данные

`users`, `api_tokens`, `decks`, `enrollments`, `items`, `progress`, `reviews`.

- Контент (`items`) отделён от прогресса (`progress`): одну колоду учат многие.
- `progress` — строка на пользователя, запись и навык.
- `reviews` хранит упражнение, оценку, введённый ответ, время и разбор ИИ.
- У `users` есть `ui_language`.

## MCP

Сервер с авторизацией по токену. Инструменты:

- создать колоду;
- добавить записи пачкой;
- прочитать колоду и трудные записи;
- исправить запись.

## Интерфейс

- Mobile-first, тёмная тема, стекло поверх цветного свечения.
- Нижняя панель «Учить / Словарь / Меню» на главных страницах, круглая «назад» — на внутренних.
- Экраны: Сегодня, Новое слово, Ввод, Разбор ошибки, Проверка ИИ, Словарь, Настройки.
- Языки интерфейса: русский, английский. Выбор лежит в `localStorage` и в профиле, читается до первой отрисовки, словари входят в сборку.

## Вне первой версии

Светлая тема, импорт колод Anki, персональные веса FSRS, нативные приложения, публикация своих колод.

## Не решено

- Стек бэкенда и фронтенда.
- Источник аудио: синтез речи браузера или готовые записи.
- Модель и провайдер для проверки ИИ.
- Хостинг и домен.
